# ionband
Tests of ionization and banding for Sirocco. This repository will contain separate folders which contains scripts (and in some cases data) for running comparisons between Sirocco and, e.g., Cloudy. 

Each folder should contain scripts for running Sirocco and plotting/analysing the results, as well as ancillary data from, e.g., Cloudy. Each folder should contain a README and/or an example script. 

Currently, these tests include:
* bb_cloudy_shell: thin shell tests of Sirocco where a single shell is illuminated by a varying temperature blackbody. Includes the capability to vary the number
